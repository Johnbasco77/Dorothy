# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this project is

This is not a code project. There is nothing to build, lint or test. It is a writing project: the user's personal reflection on the Tamil film *Dorothy*, written as a LinkedIn post.

- `Dorothy.md` holds the brief: the user's **Writing Instructions** at the top, followed by their raw notes under hashtag sections (`#Introduction`, `#Story`, `#Music`, `#Major Themes`, `#Realization`, `#Change`, `#Climax`, `#AIContext`). It is the source of truth for facts and voice. Only edit it when the user asks.
- `Dorothy_LinkedIn_Post.md` is the finished post, written from `Dorothy.md` and ready to publish. Revisions go here.
- `README.md` is the public page for the GitHub repo (github.com/Johnbasco77/Dorothy). It explains the project and how it was made. Keep it in step with any changes to the files or the process.
- `img/posters/` holds the posters for *Dorothy*, *Black* and *Oppenheimer* (the post's introduction mentions all three). `img/screenshots/` holds screenshots of the writing session, and `img/ascii/` holds an ASCII-art version of the *Dorothy* poster.

## How the post is structured

The post doesn't follow the order of the notes. It runs: introduction → story → music → climax ("first watch / second watch") → the user's own past bias (`#Change`) → realisation → Responsible AI (`#AIContext`). It ends with a line of hashtags. The `#Major Themes` list is not written out as its own section. When revising, keep this arc: the user's personal change comes right before the AI reflection, and the AI connection appears only at the end.

## Writing rules (summarised from `Dorothy.md`; the full text there takes precedence)

- **Format:** a personal movie review for LinkedIn. It should not read like a formal film review or an AI-generated article.
- **Voice:** first person, simple, human and emotionally honest. Keep the user's discomfort, past bias, realisation and change of perspective. Avoid a corporate, academic or over-polished tone.
- **No preaching:** the reflection starts with the user and their own bias, not with society.
- **Facts:** don't invent facts about the film or quietly correct them. If something looks uncertain, keep it cautious or flag it for the user to check. The film details (release years, the "38-year-old" *Veedu* reference) are kept as the user wrote them. The director's name is "Karthik Subbaraj" in both files. Ask the user before changing their notes.
- **Subjective readings:** present the user's reading of a scene or of the music (for example, why Ilaiyaraaja reused the *Veedu* background score) as the user's own interpretation, not as something the director or composer intended.
- **Lines to keep word for word:**
  - "It helped me notice the log in my own eye before pointing at the speck in someone else's."
  - "On my first watch, I questioned the climax. On my second, the climax questioned me."
  - "In both scenes, someone is discovering a beauty from within."
